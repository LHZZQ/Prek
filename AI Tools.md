## AI Usage in this project
1. AI assisted us when we were learning the Dart language at first.
2. AI helped tell us what the bugs were and how to fix them when we were dealing with errors.
3. **.github/workflows/flutter.yml**: AI guided us on how to run automatic tests on GitHub so that our code is checked every time a pull request is created.
4. **prek-app/lib/data/mock_entries.dart**: AI generated the fake reflection (e.g: Grateful for sunshine, Had a nice walk, Good chat with a friend).
