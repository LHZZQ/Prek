## AI Usage in this project
1. AI assisted us when we were learning the Dart language at first.
2. AI helped tell us what the bugs were and how to fix them when we were dealing with errors.
3. **.github/workflows/flutter.yml**: AI guided us on how to run automatic tests on GitHub so that it can deploy code changes every time a pull request is created. Especially in the "Setup and Install Flutter" section, AI helped with the configuration of the necessary files and environments for us to ensure that it is the same as our local development environment.
4. **prek-app/lib/data/mock_entries.dart**: We have not linked the database to the history page, and leaving the history page blank makes it impossible to test if the page is correct. AI generated the mock reflection entries (e.g: Grateful for sunshine, Had a nice walk, Good chat with a friend) to help show what the page will look like in the future.
5. **prek-app/coverage** : We didn't write the code coverage code manually ourselves. Instead, we used the AI to generate a set of code coverage HTML reports for us, which we can use to monitor the CI testing situation. These codes will automatically generate a report file to inform us which codes, functions or files have not been tested, and also create a very simple and easy-to-read HTML file, with distinct colors used for marking.
