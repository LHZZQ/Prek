## AI Usage in this project
1. AI assisted us when we were learning the Dart language at first.
2. AI helped tell us what the bugs were and how to fix them when we were dealing with errors.
3. **.github/workflows/flutter.yml**: AI guided us on how to run automatic tests on GitHub so that our code is checked every time a pull request is created. Especially in the "Setup and Install Flutter" section, AI automatically configures the necessary files and environments for us to ensure that it is the same as our local development environment
4. **prek-app/lib/data/mock_entries.dart**: When we do not actually store the content of the reflection in the database, leaving the history page blank makes it impossible to test whether this page is correct or not. AI generated the fake reflection, the mock entries (e.g: Grateful for sunshine, Had a nice walk, Good chat with a friend).
